# 快速开始 / 使用(Usage)

> 必选性:**必选**(纯文档仓库可省)| 适用性:全部 | 紧跟安装之后

## 模板

```markdown
## 快速开始

{1-2 个最小可运行示例,≤5 步、2 分钟跑通。}
```

## 规范

**必须做**:

- 最小可运行示例:从获取代码到跑通第一个用例
- 第一个用例选**最典型、零配置、无副作用**的路径
- 给出命令与预期结果

**建议做**:

- 与安装章的验证命令复用(装好即跑通)
- 复杂场景留给"使用示例"章节

**禁止做**:

- 超过 5 步仍未跑通(超出时应将过程脚本化:setup.sh / Makefile / npm scripts,而不是罗列长步骤)
- 需要额外配置才能跑的"快速"开始

## 量化达标线

- **≤5 步**:从获取代码到跑通第一个用例不超过 5 个步骤
- **2 分钟**:在新机器上实测,2 分钟内可跑通(不含大文件下载)
- 安装解决"装好",快速开始解决"跑通第一个用例",两者验证命令可以复用

## 示例

✅ 三条命令:克隆 → `pip install -r requirements.txt` → `python demo.py`,输出一行识别结果

❌ 快速开始要求先读完"使用示例"、配置三个密钥、再手改配置文件(步骤超限且非最小路径)
