# License

> 必选性:开源**必选** | 适用性:全部 | **必须是全文最后一节**

## 模板

```markdown
## License

{SPDX 标识,如 MIT;未授权写 UNLICENSED。}
```

## 规范

**必须做**:

- 必须是 README 全文**最后一节**,其后不得再有章节
- 使用 SPDX 标识(如 `MIT`)
- 与仓库 LICENSE 文件一致

**建议做**:

- 未授权(内部/私有)明确写 `UNLICENSED`,不留空

**禁止做**:

- 自造许可证声明;README 写 MIT 而 LICENSE 文件是其他协议

## 示例

✅ `## License` + `MIT`
