# 故障排查(FAQ)

> 必选性:推荐 | 适用性:全部

## 模板

```markdown
## 故障排查

| 现象 | 原因 | 解法 |
|---|---|---|
| {报错/异常表现} | {根因} | {具体操作} |
```

## 规范

**必须做**:

- 按"现象 → 原因 → 解法"三列组织,用表格
- 现象写读者实际看到的报错原文或表现,不写内部术语

**建议做**:

- 收录安装与快速开始路径上已知坑
- 解法给可复制的命令或配置,不给"重启试试"

**禁止做**:

- 空表占位;把issue区当FAQ链接了事

## 示例

| 现象 | 原因 | 解法 |
|---|---|---|
| `ModuleNotFoundError: No module named 'xxx'` | 未激活虚拟环境 | `source .venv/bin/activate` 后重试 |
