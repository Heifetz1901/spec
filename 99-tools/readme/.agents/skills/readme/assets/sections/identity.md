# 首屏:项目名、简介、Badges、视觉展示

> 必选性:简介**必选**;Badges、视觉展示可选 | 适用性:全部(Badges、视觉开源优先)| 位置:全文最前,TOC 之前

## 模板

```markdown
# {项目名}

{一句话简介:是什么 + 解决什么问题,<120 字符,与包描述 / GitHub description 一致}

<!-- 可选(开源):Badges,3-5 个(CI / License / 版本) -->

<!-- 可选:视觉展示——截图 / Demo GIF / 终端录制,放首屏,必须配文字说明 -->
```

## 规范

**必须做**:

- H1 全文唯一;标题下 3 行内说清项目"是什么、解决什么问题"
- 简介不超过 120 字符,与包描述字段、GitHub description 三处一致
- 视觉素材必须配文字说明(展示的是什么运行效果)

**建议做**:

- Badges 3-5 个(CI / License / 版本),只放有实际意义的,不堆砌
- 视觉展示放简介后、首屏内;CLI 工具用终端录制(VHS / asciinema)

**禁止做**:

- 简介写成能力罗列或营销长段
- 装饰性图片;为凑章节编造不存在的截图占位

## 示例

✅ `# course-video-manager` + 把课程视频自动转成带时间戳的文字稿,省去剪辑前的人工记点

❌ `# 我的项目` + 这是一个非常强大的工具,功能丰富,界面优美,支持多种场景……(超长、无信息量)
