# 目录结构

> 必选性:推荐 | 适用性:全部

## 模板

```markdown
## 目录结构

```text
{仓库布局树}
```

{关键目录一句话说明。}
```

## 规范

**必须做**:

- 布局树与仓库实际目录一致(无过时目录名)

**建议做**:

- 只列关键目录,不必全量展开
- 每个关键目录一句话说明用途

**禁止做**:

- 列出构建产物、缓存目录(.venv、node_modules、dist 等)

## 示例

```text
src/        核心源码
tests/      单元测试
docs/       详细文档(README 只保留入口)
```
