# README 骨架模板

> 使用说明（成文时删除本段）：
> 1. `{花括号}` 为占位符，替换为实际内容；标注"可选"的章节按适用性（开源/内部/库项目）取舍
> 2. 内部项目通常省略：Badges、Roadmap、贡献指南；纯文档仓库另省：安装、快速开始
> 3. 简介须 <120 字符，与包描述字段、GitHub description 一致
> 4. 全文 ≥100 行时添加 TOC；License 必须是最后一节
> 5. 安装章节四要素：Prerequisites 表（含最低版本依据）→ 编号步骤 → 密钥占位符 → 验证命令 + 预期输出
