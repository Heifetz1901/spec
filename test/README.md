# 测试用例设计 Skill

Claude Code 自定义 Skill 资源包，可供测试用例设计与评审时使用。

## 声明

本资源包基于《测试用例设计规范》整理而成，仅供学习与参考使用。

## 安装

将 `.claude` 目录复制到用户主目录下即可全局生效（所有项目均可使用）：

```bash
# Windows
xcopy /E /I .claude %USERPROFILE%\.claude\

# macOS / Linux
cp -r .claude ~/.
```

也可安装到单个项目根目录下，仅对该项目生效：

```bash
cp -r .claude /path/to/your-project/
```

安装后，Claude Code 在涉及测试用例设计时将自动激活 `test-case-design` Skill，无需额外配置。

## Skill 说明

### test-case-design

测试用例设计规范，覆盖用例设计全流程：

| 维度 | 内容 |
|------|------|
| 编号规则 | `TC-{模块}-{功能}-{序号}` 三段式编号，不可复用 |
| 优先级 | P0-冒烟、P1-关键、P2-一般、P3-边缘，含覆盖要求 |
| 设计方法 | 等价类划分、边界值分析、判定表、场景法及组合策略 |
| 用例模板 | 标准模板 + 简化模板（数据驱动） |
| 断言编写 | 可验证、具体化、完整性、无歧义 |
| 覆盖度跟踪 | 需求覆盖、等价类覆盖、判定表覆盖、场景覆盖 |
| 用例评审 | 9项自检清单 + 三级评审流程 |
| 用例维护 | 变更管理、版本管理规范 |

**激活条件：**
- 设计测试用例或编写测试计划时
- 用户提到等价类、边界值、判定表、场景法等设计方法时
- 用例评审或覆盖度检查时
- 用户提到"测试用例"、"test case"时

**设计方法选择指南：**
- 单一输入，离散取值 → 等价类划分
- 单一输入，连续数值范围 → 边界值分析
- 多个条件组合决定结果 → 判定表
- 有明确业务流程 → 场景法
