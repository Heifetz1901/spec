# 知识卡片格式

> 用法：建卡时按本文件执行。三段：模板 → 规范 → 示例。

## 模板

````markdown
---
title: {卡片名：名词，中英文取更常用者，即文件名}
tags: [{标签，小写英文优先}]
date: {YYYY-MM-DD 建卡日}
aliases: [{可选：别名/英文名/缩写}]
---

# {title}

{是什么 / 核心结论，一行，可单独背诵，直接写内容不加前缀}

## 要点

1. {不超过 5 条，每条一行、独立成句}
2. ...

## 步骤

{可选章节，仅流程类知识；一行一步：谁＋动作＋对象，阶段/状态标注行尾}

1. ...
2. ...

{可选：附一行箭头链作总览，放在编号步骤前}

```
{A} → {B} → {C}
```

## 参考

- 来源：{档案名/对话口述/链接的一句话说明，纯文本}
- {公开来源 1~2 条：佐证核心观点的官方标题或地址，如 JEP 376、openjdk.org/jeps/376}
- 相关：{可选，关键词或短语，如「ZGC 栈水位线」，不写链接}
````

## 规范

**必须做**：

- 标题下首行是全文压缩：一行讲清是什么/核心结论，可单独背诵；要点每条独立成句、离开上下文仍可读
- 要点 ≤5 条，每条一行；超过 5 条说明该拆卡，或把细节回档案层
- 卡片只留结论；论证、仲裁、考据回档案层
- 正文统一中文；同一概念全卡一个写法、与该层公共术语表一致（新术语定名后登记）；标识符保留英文（ZGC、JEP、JVM 参数、Marked0 等）；中文术语首现括注英文一次（初始标记（Mark Start））
- 步骤节一行一步（谁＋动作＋对象），阶段状态标注行尾，如（STW）、（并发）
- 数字入卡必须来自来源（档案/对话/链接），参考节可追溯；来源外的数字不自行补充
- 正文（不含 frontmatter）不超过 40 行

**建议做**：

- 关联他卡/档案用关键词或短语（纯文本），不在本卡重复展开；知识图谱由独立文件维护，不写入卡片
- 步骤节配一行箭头链作总览，编号步骤再展开；箭头链不超一行宽
- aliases 收英文/缩写别名；tags 用小写英文便于检索

**禁止做**：

- 来源仲裁（「A 记 X、B 记 Y、以官方为准」）、论证过程、考据过程进卡片
- 「大约/可能/据说」式的模糊量化
- 本地文件引用链接（[[他卡]]、[[档案]]、相对路径）——本地依赖改名/移动即失效，关联只用关键词
- 同一概念中英写法来回切换（含箭头链内混搭）；卡内私有术语表——术语对照统一走该层公共术语表

## 示例

✅ 完整示例（`research/java/jvm/gc/cards/zgc.md`，正文约 30 行）：

````markdown
---
title: ZGC
tags: [jvm, gc, low-latency]
date: 2026-10-20
aliases: [z garbage collector]
---

# ZGC

ZGC 的 GC 停顿与堆大小无关，只取决于 GC Roots 数量：标记、对象转移、引用修复全部与应用并发执行，由着色指针和读屏障保证正确性。

## 要点

1. 三个 STW 只碰根（初始标记/再标记/初始转移）→ 停顿与堆大小、存活集无关
2. 着色指针：指针位自带 GC 状态；Marked0/1 隔轮交替 = 免清零
3. 读屏障：读引用必经检查（3 条指令、~4% 开销），坏色走慢路径自愈
4. 并发转移：转发表在堆外，旧页搬空即重用；残余指针下轮标记 lazy remap
5. 代价与边界：吞吐 -9%；最坏 allocation stall（秒级）；停顿仍 ∝ 根规模

## 步骤

```
初始标记(STW) → 并发标记 → 再标记(STW) → 并发清理 → 初始转移(STW) → 并发转移 → 下轮修残余
```

1. 初始标记（STW）：翻好色 + 扫根
2. 并发标记：GC 遍历 + 读屏障自愈
3. 再标记（STW）：收尾，超时退回并发
4. 并发清理：统计存活率，选转移集
5. 初始转移（STW）：搬根直连对象 + 修根
6. 并发转移：搬转移集，读屏障查转发表自愈
7. 下轮标记：lazy remap 修残余，清转发表

## 参考

- 来源：ZGC低时延机制-20261016 档案（全部数字出处、JEP、美团/去哪儿案例）
- JEP 333 / 439 / 490；Jfokus 2018 slides
````
