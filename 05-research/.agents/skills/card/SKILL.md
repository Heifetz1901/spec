# 知识卡片工作流

把来源材料蒸馏成记忆层的知识卡片。用户给定的主题或指令作为参数传入：$ARGUMENTS

## 来源（三类都合法）

- **调研档案**（research/ 下按名搜索）：完整证据，数字出处回档案查
- **对话片段 / 口述**：一句话或一段话，来源即对话本身
- **链接**：一手来源页面

蒸馏纪律：**卡片内容不超出来源**。来源一句话就出一张薄卡——首行结论加一两条要点即可，不凑节数；缺关键信息（连「是什么」都不清）就问用户补一句；来源外的数字不进卡，不编造、不自行扩充。

## 存放位置

`research/<大主题>/<分类1>/<分类2>/cards/<卡片名>.md`，与调研档案同域；无档案的对话卡片按主题归入同样结构。

例：档案 `research/java/ZGC低时延机制-20261016.md` → 卡片 `research/java/jvm/gc/cards/zgc.md`

公共术语表放 `research/<大主题>/<分类1>/<分类2>/术语表.md`（与 cards/ 同层），同层卡片共享译名与中英对照；例：`research/java/jvm/gc/术语表.md`

## 建卡步骤

1. **定位来源**：按上节三类识别；多来源时问用户以哪个为准
2. **查重**：按卡片名在 `research/**/cards/` 搜同名卡；命中时展示旧卡，问用户覆盖、合并还是改名
3. **蒸馏**：读 `assets/template.md`，按其 模板 / 规范 / 示例 三段执行
4. **自检**：按 template.md 规范段（必须做、禁止做）逐项过检，另查内容未超出来源；任一不满足回 step 3 修
5. **确认写入**：预览全文给用户，**确认后**写盘（必要时创建目录），不确认不动文件

## 边界

- **未经用户确认不写盘**
- 卡片格式与写作规范唯一源在 `assets/template.md`，本文件不重复
