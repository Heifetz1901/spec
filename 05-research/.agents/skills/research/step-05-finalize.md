# 步骤4: 定稿确认

**目标**：用户审阅确认，文档定稿。

**操作**：

1. 向用户呈现草稿**文件路径 + 摘要**，请用户审阅
2. 用户提出意见 → 修订草稿（涉及新事实时回到步骤1补充来源），修订后再次自检（步骤3清单）：**只复检受修订影响的章节 + 全局事项**（frontmatter、来源引用编号、tags、深度适配）
3. 用户确认定稿：
   - status 按实际定值：`已结论` / `跟进中`
   - 更新 `research-session-{主题}.md`：当前步骤 → `步骤4-已完成`（仅状态，不写摘要）
   - 定稿摘要以尾注形式附于草稿末尾（不写入会话文件）：

```
## 调研完成摘要

### 调研主题
{核心问题}

### 深度 / domain
{快查/标准/深度} / {domain}

### 结论与来源
- 核心结论数: N（推测性结论 N 条）
- 来源数: N

### 输出文件
{文件路径}

### 跟进项
{无 / 逐条列出}
```

4. 询问用户是否删除 `research-session-{主题}.md`（定稿后默认可删除）

**完成标准**：文档定稿，定稿摘要已附于草稿尾注。
