# 步骤2: 分析成文

**目标**：综合来源信息形成编号化结论，按模板产出完整草稿。

**操作**：

1. 综合来源清单（草稿参考资料章节），形成**编号化结论**（C1、C2…），每条结论标注支撑来源编号（如 [1][3]）
2. **结论冲突处理**：来源间矛盾时不擅自取舍，并列呈现各方结论并标注各自来源与适用条件，冲突项列入"后续跟进"，status 保持 `跟进中`
3. 按模板章节填充草稿：
   - 问题与背景 ← 步骤0的规划摘要
   - 核心结论 ← 编号化结论（C1、C2…）
   - 详细分析 ← 展开推理过程，每节聚焦一个维度
   - 后续跟进 ← 开放问题、待验证项、信息缺口
   - 参考资料章节已由步骤1直接维护，无需填充
4. 从结论提炼**摘要**（不超过 5 条，每条一句话）
5. **章节自包含**：文档可能被分段阅读与引用，各章节不得使用"如上所述"、"见上文"等跨节指代；必要背景在节内简述
6. 推断性内容（来源未直接支撑、由分析得出）明确标注"推测"，与事实性结论区分
7. 更新 `research-session-{主题}.md`：仅步骤执行记录（结论不写入会话文件——草稿核心结论章节已有即视为持久化）

**完成标准**：草稿各章节填充完整（快查深度按其文档要求），结论已写入草稿核心结论章节（草稿已有即视为持久化）。
