# 步骤3: 自检修订

**目标**：按自检清单检查草稿质量，发现问题即修复。

**自检清单**：

- [ ] frontmatter 完整：title/date/doc_type/domain/tags/status/source 字段齐全且取值合法
- [ ] 每条核心结论都标注来源编号，且编号在参考资料中存在
- [ ] 每条结论可被出处支撑，无凭空推断；推测性内容已标注"推测"
- [ ] 详细分析每节自包含，无跨节指代
- [ ] 参考资料每条含 URL/路径和访问日期
- [ ] 时效敏感的结论标注了版本号/时间条件
- [ ] 深度为"深度"时，关键结论有至少 2 个独立来源交叉验证
- [ ] 文档要求符合调研深度（快查：摘要+结论完整；标准/深度：全章节完整）
- [ ] tags 已填写且含至少一个细分主题标签（细分分类由 tags 承担，目录只到大类）

**执行方式**：可按章节派发子代理**并行自检**——每个子代理只读取所负责的章节，对照自检清单中适用于该章节的事项检查，回传问题列表（章节 + 清单项 + 问题描述）；全局性事项（frontmatter、tags、文档要求符合深度）由主会话直接检查；自检子代理同样指定低成本档模型。

发现问题 → 修复后重新自检，直至全部通过。更新 `research-session-{主题}.md` 的步骤执行记录。

**完成标准**：自检清单全部通过。
